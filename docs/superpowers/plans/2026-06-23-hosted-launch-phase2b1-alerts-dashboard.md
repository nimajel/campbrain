# CampBrain Hosted Launch — Phase 2b-1 (Alert Scanning + Email + Dashboard) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. **Fresh-session plan — self-contained; read the cited legacy files for behavioral fidelity.**

**Goal:** Make the inert 2a `alert_enabled` flag real — a multi-user availability-alert pipeline that runs after the 6h proactive scan, matches alert-enabled saved searches against fresh Neon availability, records hits, emails each owner their new matches via Resend, and surfaces results on a gated `/dashboard`.

**Architecture:** Two new Neon tables (`hits`, `scan_runs`) replace the legacy file-based state. The scanner job (GitHub Actions) chains a new `runAlertScan` after `runProactiveScan`: load alert-enabled searches → match (core `expandStayWindows` + db queries) → DB-native reconcile into `hits` → batch one Resend email per owner for new matches → record a `scan_runs` row. A new protected `dashboard` tRPC router reads `hits`/`scan_runs` user-scoped; a gated `/dashboard` React surface renders stats + recent openings.

**Tech Stack:** Bun · Turborepo · TypeScript (strict) · Drizzle + Neon (drizzle-kit migrations) · tRPC v11 · React 19 + TanStack Router/Query + Tailwind v4 + shadcn · Resend · Vitest.

```ts
import dayjs from "dayjs";
import { weekendArrivals } from "../rules/weekend-arrivals";
import type { SavedSearch } from "@campbrain/types";

export interface StayWindow { from: string; to: string; nights: number; }

export function expandStayWindows(search: SavedSearch, today: string): StayWindow[] {
  const { datePattern, filters } = search;
  const minNights = filters.minNights;

  if (datePattern.kind === "fixed_range") {
    const { from, to } = datePattern;
    const windows: StayWindow[] = [];
    let arrival = dayjs(from);
    const lastArrival = dayjs(to).subtract(minNights, "day");
    while (!arrival.isAfter(lastArrival)) {
      windows.push({ from: arrival.format("YYYY-MM-DD"), to: arrival.add(minNights, "day").format("YYYY-MM-DD"), nights: minNights });
      arrival = arrival.add(1, "day");
    }
    return windows;
  }

  const arrivals = weekendArrivals(today, datePattern.horizonDays, minNights);
  return arrivals.map((a) => ({
    from: a.arrivalDate,
    to: dayjs(a.arrivalDate).add(a.nights, "day").format("YYYY-MM-DD"),
    nights: a.nights,
  }));
}

/** Inclusive arrival → exclusive departure date list (the nights occupied). */
export function stayDates(window: StayWindow): string[] {
  const dates: string[] = [];
  let cur = dayjs(window.from);
  const last = dayjs(window.to).subtract(1, "day");
  while (!cur.isAfter(last)) { dates.push(cur.format("YYYY-MM-DD")); cur = cur.add(1, "day"); }
  return dates;
}
```

```ts
import { expandStayWindows, stayDates, oldestCoveringScan, classifyRegion, type CampRegion } from "@campbrain/core";
import type { SavedSearch } from "@campbrain/types";
import type { QueryDb } from "./exec";
import { searchAvailableStays } from "./search";
import { getEntriesForPark } from "./entries";
import { getCatalogParks } from "./catalog";

export interface SavedSearchOpening {
  savedSearchId: string; parkPageId: string; parkName: string; campgroundName: string;
  siteName: string; arrivalDate: string; departureDate: string; nights: number;
  bookingUrl: string | null; availabilityAsOf?: string;
}

export type ParkRegionOf = (parkPageId: string) => CampRegion | null;

/** One region lookup for the whole run, from the DB catalog's coords. */
export async function buildParkRegionOf(db: QueryDb): Promise<ParkRegionOf> {
  const parks = await getCatalogParks(db);
  const map = new Map<string, CampRegion>();
  for (const p of parks) {
    if (p.latitude != null && p.longitude != null) map.set(p.parkPageId, classifyRegion(p.latitude, p.longitude));
  }
  return (id) => map.get(id) ?? null;
}

function parkPassesScope(parkPageId: string, scope: SavedSearch["scope"], regionOf: ParkRegionOf): boolean {
  if (scope.parkPageIds.length > 0) return scope.parkPageIds.includes(parkPageId);
  if (scope.region === null) return true;
  return regionOf(parkPageId) === scope.region;
}

export async function matchSavedSearchAgainstDb(
  db: QueryDb, search: SavedSearch, today: string, regionOf: ParkRegionOf,
): Promise<SavedSearchOpening[]> {
  const windows = expandStayWindows(search, today);
  if (windows.length === 0) return [];
  const { filters, scope } = search;

  const entriesCache = new Map<string, ReturnType<typeof getEntriesForPark>>();
  const cachedEntries = (pageId: string) => {
    if (!entriesCache.has(pageId)) entriesCache.set(pageId, getEntriesForPark(db, pageId));
    return entriesCache.get(pageId)!;
  };

  const openings: SavedSearchOpening[] = [];
  for (const window of windows) {
    const params: Parameters<typeof searchAvailableStays>[1] = { from: window.from, to: window.to };
    if (filters.access.length) params.access = filters.access;
    if (filters.kinds.length) params.kinds = filters.kinds;
    if (filters.hide.length) params.hide = filters.hide;

    const parks = await searchAvailableStays(db, params);
    for (const park of parks) {
      if (!parkPassesScope(park.parkPageId, scope, regionOf)) continue;
      const asOf = oldestCoveringScan(await cachedEntries(park.parkPageId), stayDates(window));
      for (const cg of park.campgrounds) {
        for (const siteName of cg.availableSites) {
          const o: SavedSearchOpening = {
            savedSearchId: search.id, parkPageId: park.parkPageId, parkName: park.parkName,
            campgroundName: cg.name, siteName, arrivalDate: window.from, departureDate: window.to,
            nights: window.nights, bookingUrl: cg.bookingUrl ?? null,
          };
          if (asOf !== undefined) o.availabilityAsOf = asOf;
          openings.push(o);

/** Upsert each opening; rows not seen at `runStart` are marked disappeared. Returns # brand-new hits. */
export async function reconcileHits(
  db: QueryDb, search: SavedSearch, openings: SavedSearchOpening[], runStart: string,
): Promise<{ newCount: number }> {
  let newCount = 0;
  for (const o of openings) {
    const res = await rows<{ inserted: boolean }>(db, sql`
      INSERT INTO hits (id, saved_search_id, user_id, provider, park_page_id, park_name, campground_name,
                        site_name, arrival_date, nights, booking_url, first_seen_at, last_seen_at)
      VALUES (${crypto.randomUUID()}, ${o.savedSearchId}, ${search.userId}, ${search.provider},
              ${o.parkPageId}, ${o.parkName}, ${o.campgroundName}, ${o.siteName}, ${o.arrivalDate}::date,
              ${o.nights}, ${o.bookingUrl}, ${runStart}::timestamptz, ${runStart}::timestamptz)
      ON CONFLICT (saved_search_id, site_name, arrival_date)
      DO UPDATE SET last_seen_at = ${runStart}::timestamptz, disappeared_at = NULL
      RETURNING (xmax = 0) AS inserted`);
    if (res[0]?.inserted) newCount++;
  }
  await rows(db, sql`UPDATE hits SET disappeared_at = ${runStart}::timestamptz
    WHERE saved_search_id = ${search.id} AND last_seen_at < ${runStart}::timestamptz AND disappeared_at IS NULL`);
  return { newCount };
}

        const openings = await matchSavedSearchAgainstDb(db, search, today, regionOf);
        const { newCount } = await reconcileHits(db, search, openings, runStart);
        hitsNew += newCount;
      } catch (err) { errors++; console.error(`alert scan: search ${search.id} failed: ${String(err)}`); }
    }

    // Notify: one batched email per owner of un-notified, currently-available, future matches.
    const toNotify = await listHitsToNotify(db, today);
    const byUser = new Map<string, NotifyRow[]>();
    for (const r of toNotify) {
      const arr = byUser.get(r.userId) ?? [];
      arr.push(r);
      byUser.set(r.userId, arr);
    }
    const apiKey = process.env["RESEND_API_KEY"];
    const from = process.env["ALERT_EMAIL_FROM"];
    for (const [, group] of byUser) {
      const rows: AlertEmailRow[] = group.map((g) => ({
        searchName: g.searchName, parkName: g.parkName, campgroundName: g.campgroundName,
        siteName: g.siteName, arrivalDate: g.arrivalDate, departureDate: g.departureDate,
        nights: g.nights, bookingUrl: g.bookingUrl,
      }));
      const res = await sendAlertEmail({ apiKey, from, to: group[0]!.email }, rows, dashboardUrl);
      if (res === "delivered") { await markNotified(db, group.map((g) => g.id), new Date().toISOString()); emailsSent++; }
      // 'skipped-unconfigured' / 'failed' → leave notified_at NULL so a future run retries
    }

    // hits_current across all users (observability)
    const current = await listHitsToNotify(db, today); // recompute is fine; or a count query — use stats per user if preferred
    await finishScanRun(db, runId, { status: "ok", searchesScanned, hitsNew, hitsCurrent: current.length, emailsSent, errors });
  } catch (err) {
    console.error(`alert scan failed: ${String(err)}`);
    await finishScanRun(db, runId, { status: "error", searchesScanned, hitsNew, emailsSent, errors: errors + 1 });
  }
}
```

> `hitsCurrent` here is an approximation (un-notified current) — acceptable observability; if an exact all-current count is wanted, add a `countCurrentHits(db, today)` to `hits.ts` and use it. Confirm `Db` is exported from the `@campbrain/db` barrel (it is — `export { ..., type Db }`) and `NotifyRow` via the `hits` barrel; the query fns accept a `Db` (it's assignable to their `QueryDb` param, as the 2a routers already rely on).
